# School Skills illustrations

Five generated, text-free classroom illustrations support the “Useful Words at
School” phrase practice. `SchoolSkillsContent.Phrase.illustrationAsset` maps each
stable phrase ID to its image. The app loads images on the existing worker thread
and shows the active prompt's illustration above the prompt text and phrase choices.

The images provide a visual context cue; the bilingual phrase choices remain the
learning targets. They do not stand for a child's actual communication, preferences,
or social behaviour.
