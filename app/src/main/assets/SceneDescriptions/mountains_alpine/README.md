# Mountains / Alpine Nature

Category ID: `mountains_alpine`

## Learning emphasis

**Primary**
- nouns
- adjectives
- visible features
- simple comparisons

**Secondary**
- action verbs
- spatial language
- sentence expansion

Wave 1 should give three different language jobs:
1. `features` — alpine animals, visible features and comparisons
2. `actions` — clear mountain-animal actions
3. `positions` — where alpine animals and features are in relation to one another

## Core noun bank

Animals:
- mountain goat / Bergziege
- marmot / Murmeltier
- rabbit / Kaninchen
- eagle / Adler
- sheep / Schaf

Environment:
- mountain / Berg
- rock / Felsen
- flowers / Blumen
- grass / Gras
- snow / Schnee
- sky / Himmel
- burrow / Bau
- hill / Hügel

## Core adjective / feature bank

Use only when visibly supported:
- big / groß
- small / klein
- brown / braun
- white / weiß
- fluffy / flauschig
- horns / Hörner
- long ears / lange Ohren
- beak / Schnabel
