# Sky / Flying Adventure

Category ID: `sky_flying`

## Learning emphasis

**Primary**
- movement verbs
- flying nouns
- sentence building around visible motion

**Secondary**
- adjectives
- comparisons
- spatial language

Wave 1 should give three different language jobs:
1. `actions` — clear flying / movement actions
2. `features` — colours, sizes, counting and comparisons
3. `positions` — where flying objects are in relation to one another

## Core noun bank

Flying things:
- balloon / Ballon
- hot-air balloon / Heißluftballon
- airplane / Flugzeug
- helicopter / Hubschrauber
- eagle / Adler
- kite / Drachen
- cloud / Wolke

Environment:
- sky / Himmel
- sun / Sonne
- mountain / Berg
- hills / Hügel
- wind / Wind

## Core verb bank

Use only when visibly supported:
- rise / steigen
- fly / fliegen
- glide / gleiten
- hover / schweben
- blow / wehen
