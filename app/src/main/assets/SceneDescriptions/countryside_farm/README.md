# Countryside / Farm

Category ID: `countryside_farm`

## Learning emphasis

**Primary**
- functional tasks
- action verbs
- everyday farm nouns

**Secondary**
- animal nouns
- adjectives
- counting
- spatial language
- sentence expansion

Wave 1:
1. `tasks` — purposeful farm jobs
2. `features` — farm animals, colours, size and counting
3. `positions` — clear spatial relationships around the farm

## Core task language

- water / gießen
- collect eggs / Eier sammeln
- feed / füttern
- carry / tragen
- sweep / fegen
- put away / wegräumen

## Core farm nouns

- watering can / Gießkanne
- egg / Ei
- basket / Korb
- chicken / Huhn
- vegetables / Gemüse
- crate / Kiste
- broom / Besen
- barn / Scheune
- coop / Hühnerstall
- garden / Gemüsegarten
