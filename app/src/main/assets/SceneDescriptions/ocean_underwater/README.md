# Ocean / Underwater

Category ID: `ocean_underwater`

## Learning emphasis

**Primary**
- verbs / actions
- concrete nouns
- spatial and positional language

**Secondary**
- visible adjectives and simple comparisons

**Low emphasis**
- functional tasks. Do not force classroom-style task language into an
  underwater scene when it is unnatural.

The category should make it easy to move from:
- `dolphin`
- `swimming`
- `the dolphin is swimming`
- `the dolphin is swimming above the turtle`
- `the big dolphin is swimming quickly above the small turtle`

without requiring every scene to contain every target.

## Core noun bank

Animals:
- dolphin / Delfin
- turtle / Schildkröte
- fish / Fisch
- clownfish / Clownfisch
- octopus / Oktopus
- crab / Krabbe
- seahorse / Seepferdchen
- jellyfish / Qualle
- starfish / Seestern

Environment:
- coral / Koralle
- seaweed / Seegras
- rock / Stein
- shell / Muschel
- sand / Sand
- bubbles / Blasen
- cave / Höhle
- water / Wasser

## Core verb bank

Prioritise actions that are visually obvious:
- swim / schwimmen
- dive / tauchen
- jump / springen
- hide / sich verstecken
- crawl / krabbeln
- float / schweben
- chase / hinterherjagen
- splash / spritzen
- eat / fressen
- carry / tragen
- look / schauen
- blow bubbles / Blasen machen

Avoid relying on verbs that cannot be confidently seen in a still image.

## Adjective bank

Use only when visually supported:
- big / groß
- small / klein
- long / lang
- short / kurz
- colourful / bunt
- bright / hell
- dark / dunkel
- striped / gestreift
- spotted / gefleckt
- many / viele
- few / wenige

Speed words such as fast/slow should only be targeted when motion cues make the
contrast genuinely clear.

## Spatial language bank

This category is especially useful for:
- above / über
- below / unter
- next to / neben
- between / zwischen
- behind / hinter
- in front of / vor
- inside / in
- outside / außerhalb
- near / nah
- far / weit weg
- over / über
- under / unter

## Scene-design target

Aim for roughly 4–6 focal subjects per image. Each scene should provide several
independent things Basti can truthfully describe without becoming a visual
search puzzle.

The initial six-scene plan is in `scene_plan.json`.
