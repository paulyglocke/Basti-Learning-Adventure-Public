# Woodland / Forest

Category ID: `woodland_forest`

## Learning emphasis

**Primary**
- nouns
- adjectives
- visible features
- simple comparisons

**Secondary**
- verbs
- spatial language
- sentence expansion

Wave 1 should give three different language jobs:
1. `features` — what the animals look like
2. `actions` — what the animals are doing
3. `positions` — where the animals are

## Core noun bank

Animals:
- deer / Reh
- rabbit / Kaninchen
- fox / Fuchs
- squirrel / Eichhörnchen
- owl / Eule
- hedgehog / Igel

Environment:
- tree / Baum
- branch / Ast
- bush / Busch
- log / Baumstamm
- mushrooms / Pilze
- leaves / Blätter
- grass / Gras

## Core adjective / feature bank

Use only when visibly supported:
- big / groß
- small / klein
- brown / braun
- red / rot
- orange / orange
- grey / grau
- bushy tail / buschiger Schwanz
- fluffy tail / flauschiger Schwanz
- long ears / lange Ohren
- big eyes / große Augen
