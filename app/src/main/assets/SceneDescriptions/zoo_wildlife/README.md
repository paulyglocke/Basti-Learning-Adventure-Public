# Zoo / Wildlife Park

Category ID: `zoo_wildlife`

## Learning emphasis

**Primary**
- animal nouns
- adjectives
- visible features
- simple comparisons

**Secondary**
- action verbs
- spatial language
- sentence expansion

Wave 1:
1. `features` — animal features and comparisons
2. `actions` — visually clear zoo-animal actions
3. `positions` — spatial relationships in the wildlife park

## Core animal language

- giraffe / Giraffe
- elephant / Elefant
- lion / Löwe
- zebra / Zebra
- penguin / Pinguin

## Core describing language

- tall / groß
- long neck / langer Hals
- big / groß
- trunk / Rüssel
- mane / Mähne
- striped / gestreift
- small / klein
- black and white / schwarz-weiß
