# Freshwater Pond — Phase 5C.5B Explore background

`canonical/freshwater_001_pond.png` is an original 1448×1086 RGB background for the child-led Freshwater Explore screen. It shows a temperate pond, a visible shoreline, reeds, lily pads, shallow underwater vegetation, stones and distant meadow/tree line. Frog and Duck are separate transparent layers under `Animals/canonical/`; no animal is embedded into the background.

The background was generated with the built-in OpenAI image generation tool for this repository task, using the current app Seasons lakeside illustration and canonical Rabbit as style references only. No external images were incorporated. The output is unlabelled and has no alpha channel by design. Generation workflow and prompt are recorded in `docs/animals-phase5c5-freshwater-review/REVIEW.md`.
