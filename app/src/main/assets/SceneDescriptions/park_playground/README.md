# Park / Playground

Category ID: `park_playground`

## Learning emphasis

**Primary**
- verbs
- everyday nouns
- everyday actions

**Secondary**
- social / functional tasks
- spatial language
- sentence expansion

Wave 1 should give three different language jobs:
1. `actions` — clear playground actions
2. `tasks` — functional and social park / playground tasks
3. `positions` — where objects/children are in the park

## Core noun bank

People / things:
- child / Kind
- ball / Ball
- scooter / Roller
- swing / Schaukel
- slide / Rutsche
- climbing frame / Klettergerüst
- sandbox / Sandkasten
- bench / Bank
- tree / Baum
