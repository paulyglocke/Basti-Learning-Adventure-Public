# Classroom / School

Category ID: `classroom_school`

## Learning emphasis

**Primary**
- functional school tasks
- action verbs
- classroom nouns

**Secondary**
- routines
- social / functional classroom language
- spatial language
- sentence expansion

Wave 1:
1. `tasks` — classroom learning tasks
2. `routines` — listening, helping and daily classroom routines
3. `positions` — spatial relationships using familiar classroom objects

## Core task language

- read / lesen
- write / schreiben
- cut / schneiden
- glue / kleben
- put away / wegräumen

## Core classroom nouns

- book / Buch
- paper / Papier
- pencil / Bleistift
- scissors / Schere
- glue stick / Klebestift
- shelf / Regal
- desk / Tisch / Schreibtisch
- chair / Stuhl
- classroom / Klassenraum
