# Jungle / Rainforest

Category ID: `jungle_rainforest`

## Learning emphasis

**Primary**
- verbs / actions
- concrete animal nouns

**Secondary**
- adjectives
- simple comparisons
- spatial language
- sentence expansion

Wave 1 should give three different language jobs:
1. `actions` — clear animal actions
2. `colours_features` — visible adjectives and comparisons
3. `positions` — unmistakable spatial language

## Core noun bank

Animals:
- monkey / Affe
- elephant / Elefant
- frog / Frosch
- parrot / Papagei
- sloth / Faultier
- tiger / Tiger
- toucan / Tukan

Environment:
- river / Fluss
- leaf / Blatt
- branch / Ast
- vine / Liane
- tree / Baum
- flowers / Blumen
- rainforest / Regenwald

## Core verb bank

Prioritise actions that are visually obvious:
- swing / schwingen
- spray / spritzen
- jump / springen
- fly / fliegen
- hang / hängen
- sit / sitzen
- walk / laufen

## Adjective / feature bank

Use only when visibly supported:
- big / groß
- small / klein
- grey / grau
- green / grün
- colourful / bunt
- striped / gestreift
- long / lang
