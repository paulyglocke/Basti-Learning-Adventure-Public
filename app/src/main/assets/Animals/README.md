# Basti's Learning Adventure — Wave 1 Animal Art

This pack contains the approved first-pass visual style reference plus 11
individual language-neutral PNG assets for app integration.

Canonical Wave 1:
- dinosaur
- snake
- crocodile
- dragon
- whale
- fish
- horse
- dog
- cat
- rabbit
- mouse

Production direction:
- friendly and child-appropriate
- consistent visual family
- whole-animal readable silhouettes
- no baked-in labels
- semantic IDs remain separate from filenames
- transparent PNG is used for this art-review/integration stage

Important:
The individual PNGs were isolated from the approved generated Wave 1 sheet.
Review them visually in the app before treating edge cleanup as final production
master artwork. The reference sheet is retained under Animals/reference/.
