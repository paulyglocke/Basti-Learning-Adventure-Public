# Basti's Learning Adventure — Wave 2 Animal Art

This pack contains nine individual transparent PNG assets plus a Wave 2
reference sheet.

Wave 2:
- T-Rex
- Velociraptor
- Pteranodon
- Mosasaurus
- Great White Shark
- Dolphin
- Eagle
- Monkey
- Mammoth

Production direction:
- friendly and child-appropriate
- consistent visual family with Wave 1
- whole-animal readable silhouettes
- no baked-in labels
- transparent PNGs
- reusable canonical assets rather than activity-specific duplicates

Canonical destination:
app/src/main/assets/Animals/canonical/

The updater only copies these assets and the Wave 2 reference/manifest files.
It does not delete or modify existing source code or Wave 1 artwork.
