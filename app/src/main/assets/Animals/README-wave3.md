# Basti's Learning Adventure — Wave 3 Animal Art

This pack contains eight individual transparent PNG assets plus a Wave 3
reference sheet.

Wave 3:
- Turtle
- Mole
- Basking Shark
- Deer
- Alligator
- Orca
- Anaconda
- Bear

Production direction:
- friendly and child-appropriate
- consistent visual family with Waves 1 and 2
- whole-animal readable silhouettes
- no baked-in labels
- transparent PNGs
- reusable canonical assets rather than activity-specific duplicates

Canonical destination:
app/src/main/assets/Animals/canonical/

The updater only copies these assets and Wave 3 support files.
It does not delete or modify existing source code or earlier animal artwork.
