# School action illustrations

Five text-free, generated storybook scenes illustrate the classroom actions in the
School Skills listening round. `SchoolActionsContent.Action.illustrationAsset` maps
each stable action ID to its image. Pictures form the answer choices alongside bilingual
text labels; instructions remain spoken and visible. The five images are loaded on the
existing worker thread.

This round measures picture matching of authored instructions only. It does not mean
the child completed the physical action or follows classroom directions generally.
