# School action illustrations

Five text-free, generated storybook scenes illustrate the classroom actions in the
School Skills listening round. `SchoolActionsContent.Action.illustrationAsset` maps
each stable action ID to its image. Pictures form answer choices alongside bilingual
text labels in the one-step round, and are composed in two- or three-picture order for
the advanced sequence rounds.
Instructions remain spoken and visible. The five images are loaded on the existing
worker thread.

The sibling `board/` directory contains four item tiles and seven destination tiles for
the touch-based Classroom Helper activity. The item and place IDs map to these separate
images; these tiles represent board objects/targets, not activity evidence by themselves.

This round measures picture matching of authored instructions only. It does not mean
the child completed the physical action or follows classroom directions generally.
