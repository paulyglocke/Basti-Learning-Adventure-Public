# Basti’s Learning Adventure — Version 1

The first offline English/German Android version includes animal actions,
number practice up to 9,999, maths within 10, positions, letters, days and
seasons, mixed rounds, and 53 animated verb lessons.

- Settings persist locally; phone and tablet layouts adapt automatically.
- Lesson navigation returns to the same quiz question.
- All learning content and animations are bundled; no Google Play Services.
- Local build and lint passed (zero errors); all nine browser checks passed.

Download **Basti-Learning-Adventure-V1-debug.apk** below and open it on your
Android device to install. This is a debug-signed sideload build for Android 6+
(minimum API 23). Native launch and actual TTS audio still require testing on
Samsung and Fire devices. English/German offline voice data must be installed
for speech. See BUILD_NOTES.md for the complete verification details.

The release APK is the same verified binary supplied with this version;
separately generated CI debug APKs use a different signing key.
