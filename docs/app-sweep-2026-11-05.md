## Fix first

### 1. Older animal Vocabulary sessions are no longer opened — P1, code/history confirmed

Before `cf3f912`, the ViewModel used `vocabulary-find` and `vocabulary-name`.
The category expansion changed animal sessions to `vocabulary-animals-find`
and `vocabulary-animals-name`. The current owner has no fallback/migration for
the old names. An upgraded installation with an older unfinished animal round
will open a new round instead of resuming it. Old files are retained and shared
progress history is separate; this is not evidence that progress records were
deleted.

Source: [VocabularyViewModel](../app/src/main/java/com/bellfamily/bastischool/ui/vocabulary/VocabularyViewModel.kt),
lines 33–39; compare `git show cf3f912^:app/src/main/java/com/bellfamily/bastischool/ui/vocabulary/VocabularyViewModel.kt`.

Repair: resolve an existing current journal first, then safely recover the
legacy journal when no current one exists. Define which journal wins when both
exist, preserve failed writes, and test an actual upgrade fixture. Do not
overwrite an existing newer session or clear either saved record.

### 2. Habitat Matching loses its return page through Options restoration — P2, reproduced

Reproduction: All Activities → Match Animals to Habitats → Options → Activity
recreation → Back → Back. The app returns to root Home rather than All Activities.
The same gap loses the Animals category when that was the origin.

`ShellNavigation.restore` recognizes `HABITAT_MATCH` directly, but omits it
from the Options-origin habitat set at lines 123–124. Saved `homePage` therefore
falls back to `home`. Ordinary Options open/close without recreation works.
Existing navigation tests cover direct matching restoration, missing this case.

Source: [ShellNavigation](../app/src/main/java/com/bellfamily/bastischool/ShellNavigation.kt).
Temporary desired-behavior JVM probe failed with `expected:<all> but was:<home>`.
An API 35 production-navigation probe confirmed root Home is displayed.

Repair: include the matching Options origin in restoration and add regression
cases for both `all` and `category:ANIMALS`. Preserve the current general
activity-root Back-to-Home policy; this is a specific broken origin contract.

### 3. Classroom Things repeats word targets prematurely — P2, reproduced

Food & Drink now visits every word before repeating. Classroom Things still
shuffles 24 question variants as independent candidates. Different variants of
one word can occur before the eight-word pool has been explored.

Exact reproduction: FIND, five questions, seed 1 produces
`book, pencil, teacher, desk, book`. There are only four distinct word targets.
Task IDs are distinct, so existing task-uniqueness checks do not catch this.

Source: [VocabularyContent](../app/src/main/java/com/bellfamily/bastischool/learning/vocabulary/VocabularyContent.kt),
lines 122–137. Temporary five-distinct-target probe failed at seed 1.

Repair: apply the target-cycle policy used by Food & Drink, varying answer sets
on necessary repeats. Preserve already saved classroom plans during the change.
Animal vocabulary's six-word pool also permits necessary repeats in ten-round
practice; that documented bounded-pool behavior is separate.

### 5. Wash Hands is still a text-only sequencing task — P2, code confirmed

`WashHandsScreen` renders names and numbered positions, with no image/Canvas
step illustrations. A child who cannot read must repeatedly listen to identify
the choices. Add four clear, consistent pictures aligned to the existing step
IDs and retain their spoken labels and current sequence behavior. This is a
good small artwork improvement before another large feature.

Source: [WashHandsScreen](../app/src/main/java/com/bellfamily/bastischool/ui/washhands/WashHandsScreen.kt),
lines 29–55; [WashHands content](../app/src/main/java/com/bellfamily/bastischool/learning/washhands/WashHands.kt).

### 6. Options makes Number level appear global — P2, scope mismatch

Options offers 10/20/50/100 and says “Current maximum”. That setting is passed
to legacy number practice, while native Maths uses each activity's own fixed
range. A parent can select 100 and still receive a five-space native activity.
Clarify which exercises use this setting and expose level choices only where
the exercise actually supports them.

Source: [MainActivity](../app/src/main/java/com/bellfamily/bastischool/MainActivity.kt),
`NativeOptions` lines 1291–1293, `settingsJson` and native configure calls.
The Follow home description also still says one/two steps although the chooser
now includes classroom, two-/three-action and manipulation tasks.

### 7. Celebration variety is limited to the same five animals — P3, optional

The shared native celebration rotates dinosaur, snake, crocodile, whale and fish
but keeps that same set for every completion. More variety can come from the
existing canonical library with appropriate bilingual labels. Reusing a
canonical animal across learning activities is useful semantic consistency;
it does not call for generating another copy of that animal.

Source: [CelebrationState](../app/src/main/java/com/bellfamily/bastischool/ui/common/CelebrationState.kt).

## Remaining HTML → Kotlin migration

The Home inventory contains 27 entries: 22 native destinations and five WebView
destinations. HTML still renders learning/reward emoji and has weaker round-wide
repetition safeguards than the newer native exercises.

| Existing entry | What remains in HTML | Native migration requirement |
| --- | --- | --- |
| Learn Verbs | 53 lessons, bilingual explanations/examples and CSS action animations | Extract one shared verb catalogue and build native Explore/listen/action presentation |
| Animal Actions | Quiz driven by the same verb catalogue, with an inline lesson route | Migrate alongside Learn Verbs, preserving quiz↔lesson return state and native progress/rewards |
| Numbers | Visual counting to 20; before/after/missing/hear; largest/smallest; tens/ones; selectable ceiling to 100 | Preserve these modes/ranges; the existing native 1–5 activities do not replace them |
| Easy Maths | Addition and story subtraction within 10 | Reuse native arithmetic infrastructure; cover subtraction beyond the current within-5 native slice |
| Mixed Adventure | Mixes six legacy families, including old letter/time/position representations | Migrate after constituent native curricula have parity; provide mixed-session restoration and per-skill progress |

Sources: [HomeCatalogue](../app/src/main/java/com/bellfamily/bastischool/ui/home/HomeCatalogue.kt),
[app.js](../app/src/main/assets/app.js) (`verbQs`, `renderNumberPractice`,
`renderMath`, `startGame`, `renderVerbLibrary`, `openVerbLesson`).

The verb catalogue has 39 distinct target animals. Twelve have direct canonical
matches using the existing crocodile alias. The other 27 require artwork/species
review; a generic “shark” must not silently become a particular species. Also
review whether the art/animation actually demonstrates each action, rather than
just displaying an animal. Full verb migration is larger than replacing a few
HTML buttons. Keep the existing route available until native parity is tested.

Recommended order: shared native Verbs/Animal Actions, then Numbers progression,
then Easy Maths consolidation and finally native Mixed Adventure. A smaller
arithmetic consolidation could be taken first if a quicker migration is desired.

## Asset and loading findings

- Scanned 229 image files under main assets/resources, totaling 376.1 MB.
  SHA-256 comparison found **zero byte-identical duplicate groups**. Visual
  repetition is mainly mapping/reuse, not duplicate files on disk.
- SceneDescriptions contains 83 images totaling 201.7 MB; Prepositions contains
  52 totaling 104.3 MB. The largest individual PNGs are about 3 MB. Consider
  optimized copies for opaque scene artwork, using Food & Drink's JPEG approach
  as a local precedent. Retain originals and compare quality at actual device
  sizes before changing mappings; preserve alpha for cutout animals.
- `FollowViewModel.setVisible` loads every instruction/school image family on
  first entry, even for an introductory level. Load only the selected family's
  assets and cache by family. The unnecessary I/O is code-confirmed; no measured
  startup delay is claimed here.
- `homeAsset` performs file reads/bitmap decode inside composition. A bounded
  background cache would improve resilience and reduce main-thread work; jank
  was not measured in this pass.
