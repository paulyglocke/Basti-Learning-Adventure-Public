# Canonical animal and artwork inventory

## Identity and evidence rules

The repository has 28 standalone files under `app/src/main/assets/Animals/canonical/`, but it does **not** yet have a shared canonical animal-definition table. Filenames are asset names, not guaranteed semantic IDs. Only six Vocabulary records are typed as `animal.*`; Follow Instructions uses `object.follow.*`; Animal Groups reuses some string IDs but owns its own definitions; scene descriptions use scene-local target IDs/phrases. The table below records visible repository use and does not silently unify those contracts.

All files are PNG. Wave 1 is transparent RGBA, 282–374 px per side and described in `Animals/README.md` as isolated first-pass art needing edge/in-app review. Wave 2 and 3 are 1254×1254 transparent RGBA per manifests. Wave 2/3 READMEs say the art is intended as a consistent family, but the audit did not perform a full 28-image style review. Composite images are separately inventoried in [Artwork Gaps](ARTWORK_GAPS.md).

“Fact/action evidence” below means a current authored example or scene annotation, not a reviewed global biological rule. “Not in canonical record” means author new, sourced content before teaching or scoring it.

## Other pictured animals without standalone canonical cutouts

SceneDescription composites and legacy emoji/content include frog/Frosch, duck/Ente, earthworm/Regenwurm, ant/Ameise, badger/Dachs, bird/Vogel, butterfly/Schmetterling, seal/Robbe, otter/Otter, crab/Krabbe, octopus/Oktopus, seahorse/Seepferdchen, clownfish/Clownfisch, owl/Eule, squirrel/Eichhörnchen, hedgehog/Igel and many farm/zoo subjects (including lion, giraffe and elephant). Their presence in a composite or emoji dictionary does not mean an independently reusable canonical PNG exists. Use the actual scene image only when its visible target and language metadata match the claim; do not crop it and call the crop canonical without a visual/licensing review.

### Animal Groups non-negotiable compatibility

The original four-object set remains **Whale, Dolphin, Horse, Rabbit** with its current Water/Land rule and `activity.discover.animal_groups` revision 1, `animal-groups-session` AGR1 journal, existing decoder, `skill.discover.animal_habitat` and `context.discover.water_land`. Any future expanded introductory Water/Land set requires a separate reviewed content/activity identity (or a separately owner-approved migration proven by exact restoration tests). Do not alter old saved sessions, labels, progress history or route return behavior as a side effect of adding habitat exploration.
