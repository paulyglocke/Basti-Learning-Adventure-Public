# Animals & Habitats — proposed curriculum and content review

## Current implementation

**Animal Groups / Tiere zuordnen** is a native fixed-set tap-to-place sort. It contains four animals and exactly two exclusive categories: Water and Land. Whale and dolphin map to Water; horse and rabbit map to Land. Each object has one accepted category, an EN/DE label and a short habitat hint. Four individual canonical PNGs and two separate habitat cue illustrations are available. Selection, category taps, Help, Listen/replay, correction, durable restore and shared progress are implemented.

This is a defensible first contrast with the current four chosen examples, but it is not a general animal-habitat model. In particular, the reusable `SortRule` assigns one category to every item. It must not classify all animals into one mutually exclusive Water/Land/Air taxonomy. A frog can use water and land through its life cycle; ducks use land and water and can fly; crocodiles/alligators are semi-aquatic; turtles vary by species. Later content must represent more than one valid relation, or ask about a specific scene/action where only one answer applies.

### Existing reusable animal data and IDs

There is **not yet a shared canonical `AnimalDefinition` catalogue**. `VocabularyContent` has six `animal.*` records (dinosaur, snake, whale, horse, crocodile, fish), with bilingual names, one example sentence, one Find prompt and a canonical-asset selector. Animal Groups refers to the shared whale/horse records, but defines dolphin/rabbit names and habitat claims locally. Follow Instructions owns `object.follow.*` semantic object records for its six-target pool (crocodile, dinosaur, snake, fish, horse, whale), each mapped to a canonical image. Legacy Animal Actions stores animal keys as JavaScript object keys and the 53 verb records. Tell Me stores scene target words as localized authored strings. Prepositions has its own finite animal enum. These are real reuse points, but IDs are not consistently unified.

Current structured facts are limited: Animal Groups has four local Water/Land assignments and help sentences; Vocabulary has six one-sentence examples; Animal Actions has one target animal per verb prompt. There is no central reviewed habitat list, movement set, feature list, or living/extinct metadata. Detailed Tell Me scene facts stay correctly attached to a particular illustration and must not be promoted to universal animal facts without review.

## Scientific rules for future content

1. Store distinct relation types: habitat (where an animal lives), movement capability/action (how it moves or what it is doing), and physical feature (what it has). A record may have multiple values in each relation.
2. Ask one clear question per task. A static still must visibly support the claimed action; an ability question must accept the reviewed full answer set.
3. Use a one-answer sorting engine only for content authored to have exactly one valid category under an explicit simplified rule. Do not flatten general habitat data into `SortItem(item, category)`.
4. Give habitat activities actual context—ocean, woodland, shore, wetland, grassland—not just pictograms labeled Air/Water/Land. “Air” describes where movement occurs, not a habitat.
5. Keep school-age descriptions simple, but facts accurate. Separate a pictured scene observation (“the dolphin is jumping”) from a species fact (“dolphins breathe air”).
