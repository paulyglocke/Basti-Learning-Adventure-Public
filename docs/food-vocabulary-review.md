# Food & Drink vocabulary — 2026-11-05

Food & Drink adds eight bilingual words to Vocabulary Booster: Apple/Apfel,
Banana/Banane, Bread/Brot, Water/Wasser, Milk/Milch, Cheese/Käse,
Orange/Orange and Sandwich/Sandwich. Each word has an example sentence,
manual listening controls, Explore artwork and Find/Name practice.

Food practice uses `activity.vocabulary.food.find` and
`activity.vocabulary.food.name`, with independent `vocabulary-food-find` and
`vocabulary-food-name` journals. The current browsing checkpoint already stores
category identity; no new checkpoint schema is needed. Legacy animal browsing
checkpoints remain readable. Existing animal and classroom activity identities
and content versions are retained.

## Repetition and restoration

Five-question rounds choose five different targets. Ten-question rounds visit
all eight words before repeating, avoid adjacent repeated targets at the cycle
boundary, and vary the answer set when a target returns. A repeated picture can
therefore occur twice in a ten-question round; the same complete question does
not recur. Seeded generation is deterministic. Restoring uses the saved plan
and preserves question/choice order and support state. Choices stay inside the
food set, with four distinct answers and one correct answer.

## Artwork

Eight original images were generated with the built-in image generation tool
and reviewed as isolated, identifiable objects on the existing warm paper
background. Bundled assets are in `app/src/main/assets/vocabulary/food/`;
the [asset README](../app/src/main/assets/vocabulary/food/README.md) records the
prompt set and subjects. Optimized 512px JPEGs total approximately 524 KB.
`VocabularyArtworkLoader` decodes them through the existing bounded cache.
